UpHere

Projeto de gerenciamento de arquivos com a possibilidade de login e registro. A página principal contém a possibilidade de upload de arquivos, além de logout e exclusão de conta.

Neste projeto, reutilizei o sistema de autenticação de usuário que publiquei em meu portfólio. Você pode dar uma olhada nele clicando aqui! Utilizei o MongoDB Atlas para o armazenamento de dados do usuário, tais como informações de login e dados sobre os arquivos enviados. Supabase Storage foi utilizado para realizar o armazenamento de arquivos em nuvem. O usuário tem a liberdade de escolher qualquer tipo de arquivo, seja ele vídeo, áudio, imagem ou documentos de textos. Também é possível fazer o upload de múltiplos arquivos simultâneamente, além de realizar a exclusão de tais arquivos quando desejar.
